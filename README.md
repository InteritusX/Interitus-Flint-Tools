# Interitus' Flint Tools

Interitus' Flint Tools shakes up the early game progression by forcing players to obtain flint tools before progressing to stone.
Flint tools are slightly better than their wooden counterparts, offering more durability and slightly higher attack damage.

You now require at least a wooden shovel to mine gravel. Three gravel can then be crafted into flint, and with that flint you can craft a brand new set of flint tools!
